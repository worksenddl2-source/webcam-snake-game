# 🐍 웹캠으로 조종하는 뱀게임

Teachable Machine으로 학습한 **웹캠 이미지 분류 모델**로 방향을 바꾸는 웹 뱀게임입니다. 손짓이나 몸짓으로 뱀을 움직여 보세요.

> 📅 2026-10-25 실습 · HTML 파일 하나(`index.html`)로 동작

---

## 🎯 학습 목표
1. 미리 학습된 이미지 분류 모델을 웹페이지에 불러와 쓸 수 있다.
2. 분류 결과(클래스 + 확률)를 게임 입력으로 바꿀 수 있다.
3. 웹캠 페이지가 멈추는 원인을 이해하고 고칠 수 있다.

---

## ▶ 실행 방법

웹캠은 보안 정책 때문에 `http://localhost`나 `https`에서만 제대로 동작합니다. 파일을 더블클릭해서 열면(`file://`) 카메라가 안 켜질 수 있어요.

```bash
cd snake
python -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

1. **📷 웹캠 시작** 버튼을 누르고 카메라 권한을 **허용**합니다.
2. 상태 줄이 `1/2 카메라 켜는 중...` → `2/2 모델 불러오는 중...`으로 바뀐 뒤 준비가 끝납니다.
3. **▶ 게임 시작** 버튼을 누릅니다.

| 조작 | 방법 |
|---|---|
| 방향 바꾸기 | 웹캠 앞에서 왼쪽·오른쪽·위·아래 동작 |
| 키보드 | 방향키로도 조작 가능 |
| 다시 시작 | 게임 오버 후 스페이스바 |
| 인식 기준 | 슬라이더 (기본 0.80, 0.50 ~ 0.99) |
| 속도 | 슬라이더 (기본 150ms, 60 ~ 400ms) |

## 🧠 핵심 개념

| 개념 | 설명 |
|---|---|
| **Teachable Machine** | 구글의 노코드 학습 도구. 웹캠 사진을 클래스별로 찍어 분류 모델을 만들고 `model.json` + `metadata.json`으로 내보낸다. |
| **이미지 분류** | 사진 한 장 전체가 "어느 클래스인지"와 그 확률을 낸다. 물체의 위치(박스)는 알려주지 않는다. |
| **신뢰도 임계값** | 가장 높은 확률이 기준보다 낮으면 무시한다. 애매한 동작 때문에 방향이 바뀌는 것을 막는다. |

사용한 모델: https://teachablemachine.withgoogle.com/models/o7yJcwkL5/
클래스: **왼쪽 · 오른쪽 · 위 · 아래 · 중립**

## 🧩 코드 살펴보기

### 1) 모델 불러오기
```js
const MODEL_URL = "https://teachablemachine.withgoogle.com/models/o7yJcwkL5/";
model = await tmImage.load(MODEL_URL + "model.json", MODEL_URL + "metadata.json");
```

### 2) 클래스 이름 → 방향
```js
function labelToDir(name) {
  const n = name.trim().toLowerCase();
  if (n.includes("왼") || n.includes("left"))  return "LEFT";
  if (n.includes("오른") || n.includes("right")) return "RIGHT";
  if (n.includes("위") || n.includes("up"))    return "UP";
  if (n.includes("아래") || n.includes("down")) return "DOWN";
  return null; // 중립 등
}
```
클래스 이름에 한글이나 영어 방향 단어가 들어 있으면 인식합니다. 모델을 다시 학습해도 이름 규칙만 맞추면 그대로 쓸 수 있어요.

### 3) 안전장치
- **중립**이거나 신뢰도가 기준보다 낮으면 → 방향을 바꾸지 않고 가던 대로 갑니다.
- **정반대 방향으로는 바로 꺾지 못하게** 해서, 인식이 한 번 틀려도 바로 죽지 않습니다.
- 최고 점수는 `localStorage`에 저장됩니다.

### 4) 함수 구성
```
startCam  → 카메라 켜기 → 모델 불러오기
predictLoop / predict → 0.1초마다 인식 → setDirection
startGame → tick → step (이동·먹이·충돌) → draw
                       └ gameOver
```

## 🔧 트러블슈팅: "카메라를 켜려는데 멈춰 있어요"

처음 버전에서 실제로 겪은 문제입니다.

| 원인 | 해결 |
|---|---|
| 인식 결과가 나와야 다음 화면을 그리는 구조 → 인식이 느리면 화면도 멈춰 보임 | **화면과 인식을 분리**: 영상은 `<video>`로 계속 재생하고, 인식은 0.1초마다 따로 실행 |
| 모델을 다 받은 뒤에야 카메라를 켬 | **카메라를 먼저** 켜고 모델은 그다음에 불러오기 |
| 어디서 멈췄는지 알 수 없음 | 상태 줄에 진행 단계 표시, 권한 거부·카메라 사용 중 같은 오류를 한국어로 안내 |

그래도 안 되면 확인하세요.
- 주소가 `http://localhost:8000`인지 (Ctrl+F5로 새로고침)
- 브라우저 카메라 권한을 **허용**했는지
- 줌, 카톡 영상통화, 다른 탭처럼 카메라를 쓰는 프로그램을 닫았는지
- F12 → Console 탭의 빨간 오류

> 💡 **좌우 반전:** 웹캠 화면은 거울처럼 뒤집혀 보이고, 모델에도 반전된 화면을 넣습니다(Teachable Machine 학습 화면과 같게). 왼쪽·오른쪽이 거꾸로 인식되면 반전 설정을 확인하세요.
